
# Enhanced LSTM for Time Series Forecasting

## Project Overview
This project implements an Enhanced Long Short-Term Memory (LSTM) neural network for time series forecasting.

The model is designed to analyze historical time-series data and predict future values using deep learning techniques.

## Dataset
- Dataset: ETTh1
- File: ETTh1.csv
- Type: Electricity Transformer Temperature dataset

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Files
- Enhanced_LSTM_Time_Series_Forecasting.ipynb – Model implementation and analysis.
- ETTh1.csv – Dataset.
- Enhanced_LSTM_IEEE_Research_Paper.pdf – Research paper.
- Enhanced_LSTM_Project_Results.pdf – Project results.

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells.
